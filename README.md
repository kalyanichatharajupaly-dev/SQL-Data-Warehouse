# SQL Data Warehouse Project | MySQL

This project demonstrates an end-to-end SQL Data Warehouse solution, from raw data ingestion to generating business insights using MySQL.

---

## 🚀 Project Requirements

### Building the Data Warehouse (Data Engineering)

#### Objective
Develop a centralized SQL Data Warehouse using MySQL to integrate CRM and ERP data for analytical reporting and decision-making.

#### Specifications
- **Data Sources:** CRM and ERP datasets provided as CSV files.
- **Data Ingestion:** Load raw data into the Bronze layer.
- **Data Quality:** Clean and resolve data quality issues.
- **Data Integration:** Combine data from both source systems.
- **Data Modeling:** Build analytical tables in the Gold layer.
- **Documentation:** Document the data warehouse architecture and workflow.

---

### 📊 BI: Analytics & Reporting (Data Analytics)

#### Objective
Generate business insights using SQL-based analytical queries.

#### Key Areas
- **Customer Behavior**
- **Product Performance**
- **Sales Trends**

These insights help stakeholders understand business performance and support informed decision-making.

## 🏗️ Data Architecture

The project follows the Medallion Architecture:

- **Bronze Layer:** Stores raw CRM and ERP data.
- **Silver Layer:** Cleans, standardizes, and integrates data.
- **Gold Layer:** Stores business-ready data for analysis and reporting.

---

## 🎯 Project Goal

Transform raw data from multiple sources into clean, integrated, and business-ready information using SQL.
